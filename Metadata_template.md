## Field Descriptions

**Source URL:** 
- The exact, complete URL where you retrieved the text
- Must be the official government or authoritative source

**Retrieved Date:**
- Today's date when you collected the source
- Format: YYYY-MM-DD (e.g., 2025-11-13)

**Collected By:**
- Your name: Sourabh

**Source Type:**
- Describe the source format
- Examples: "Official Government Website (govinfo.gov)", "Official PDF", "Virginia LIS HTML", etc.

**Verification Status:**
- Always start with: "Pending Review"
- Will be updated to "Verified" after review

**Citation:**
- The legal citation for the source
- Include USC/CFR/Virginia Code section numbers
- Example: "42 USC §3601 et seq."

**Notes:**
- Any additional important information
- Examples: PDF date, special formatting notes, collection method, etc.
- If no official PDF available, note here
