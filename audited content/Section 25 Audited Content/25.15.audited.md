# Concurrent Licenses for Brokers

<!-- If you're considering becoming a broker and want the flexibility to be active in more than one firm, it's important to understand the rules surrounding **concurrent licenses**. According to regulations set forth by the board, you can be issued concurrent licenses, but there are specific steps you need to follow. -->
Brokers seeking to be active in more than one firm must understand the rules surrounding **concurrent licenses**. According to board regulations, concurrent licenses can be issued, but specific steps must be followed.

## Steps to Obtain Concurrent Licenses

1. **Submit a Concurrent License Form**
   - This form is the official request to hold licenses for more than one firm simultaneously.
   - It signals commitment to managing responsibilities across multiple professional environments.

2. **Notify Each Principal Broker**
   - Ensure that each **principal broker** (the main broker at each firm) is fully informed of the plans.
   - Provide written statements verifying that each principal broker has been notified of the concurrent licensure status.
   - This step ensures transparency and maintains trust among all parties.

3. **Pay License Fees for Each Firm**
   - Payment is required for each license sought.
   - Unlike a one-time license fee, concurrent licenses require separate fees for each firm.
   - Consider the financial feasibility of holding multiple licenses.

## Stipulation

- If applying to be associated with a firm where a license was previously held that has now expired, the applicant is **not eligible** for a concurrent license with that firm until the expired license is **reinstated**.
- This rule emphasizes maintaining current license status.
