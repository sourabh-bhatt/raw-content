# Concurrent License: Working Across Multiple Firms

<!-- When you're interested in being active in more than one firm as a **broker**, you need to obtain a **concurrent license**. This license allows you, and only brokers like you, the flexibility to work across multiple firms simultaneously. -->

When a **broker** wants to be active in more than one firm, they need to obtain a **concurrent license**. This license allows only brokers the flexibility to work across multiple firms simultaneously.

## Steps to Obtain a Concurrent License

1. **Pay the application fee:** Be prepared to cover the required fee for the application process.

2. **Submit an official application:** Complete and send in the necessary paperwork to apply for the license.

<!-- 3. **Obtain sponsorship from each firm:** You must obtain sponsorship from the **principal broker** at each firm where you plan to be active. -->
3. **Obtain sponsorship from each firm:** Brokers must obtain sponsorship from the **principal broker** at each firm where they plan to be active.

<!-- 4. **Provide written verification:** Before submitting your application, you must provide written verification that you have obtained sponsorship from the **principal broker** at each firm where you plan to be active. -->
4. **Provide written verification:** Before submitting the application, brokers must provide written verification that they have obtained sponsorship from the **principal broker** at each firm where they plan to be active.
