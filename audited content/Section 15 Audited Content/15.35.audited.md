# Exercising Ordinary Care When Representing a Seller

<!-- When you represent a seller as their **agent**, you must use **ordinary care**. This means you must use the same **judgment** that a reasonable person would use in the same situation. -->
When representing a seller as their **agent**, agents must use **ordinary care**. This means using the same **judgment** that a reasonable person would use in the same situation.

<!-- You must act like a careful and responsible person would act. Make choices for your client that meet normal expectations. -->
Agents must act like a careful and responsible person would act. Make choices for clients that meet normal expectations.

<!-- This protects both you and your client. It is a basic part of your **duties as an agent**. -->
This protects both the agent and the client. It is a basic part of **duties as an agent**.
